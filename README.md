# .github
Org-wide defaults: SECURITY policy, profile README, CODE_OF_CONDUCT, pull request template and workflow templates.

- `PULL_REQUEST_TEMPLATE.md` — default PR template for every repository that has none of its own.
- `workflow-templates/clp-gates.yml` — caller for the shared [CLP Gates](https://github.com/CyberLegionLtd/clp-gates) (Actions → New workflow → "CLP Gates"). Pin both `uses:` and `gates-ref` to the same reviewed clp-gates commit.
