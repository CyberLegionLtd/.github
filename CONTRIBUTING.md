# Contributing

Cyber Legion's repositories are private, and contributions are by invitation.
This repository holds the organisation's public profile and community-health
files; it is not the place to find engineering process documentation.

## Reporting a vulnerability

See [SECURITY.md](SECURITY.md). Do not open a public issue for a security problem.

## Everything else

Use the route described in [SUPPORT.md](SUPPORT.md), or contact your Cyber Legion
point of contact.
